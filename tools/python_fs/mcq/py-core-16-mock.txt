?2 [Mock · Scope] What does this program print?


(b) `10 5`
(c)* `11 5`

?1 [Mock · Production] An `async def` endpoint slows down as traffic rises, yet CPU use stays low. The most likely cause is
(a) too few Python versions
(b)* a blocking call (synchronous I/O or `time.sleep`) on the event loop, stalling every other request
