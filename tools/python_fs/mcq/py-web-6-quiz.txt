?2 [Routing] What does this program print?
```python
from fastapi import FastAPI
from fastapi.testclient import TestClient

app = FastAPI()

@app.get("/items/{item_id}")
def read(item_id: int, q: str | None = None):
    return {"id": item_id, "q": q}

client = TestClient(app)
print(client.get("/items/5?q=pen").json(), client.get("/items/x").status_code)
```
(a) `{'id': 5, 'q': 'pen'} 404`
(b) `{'id': '5', 'q': 'pen'} 422`
(c)* `{'id': 5, 'q': 'pen'} 422`
(d) `{'id': 5, 'q': None} 422`
=> The path segment is converted to `int` by the annotation, `q` comes from the query string, and `x` cannot be converted, so FastAPI answers 422 before calling the function.

?2 [Dependencies] What does this program print?
```python
from fastapi import Depends, FastAPI
from fastapi.testclient import TestClient

app = FastAPI()
log = []

def get_resource():
    log.append("open")
    try:
        yield "res"
    finally:
        log.append("close")

@app.get("/")
def handler(resource: str = Depends(get_resource)):
    log.append("handler")
    return resource

TestClient(app).get("/")
print(log)
```
(a) `['handler', 'open', 'close']`
(b) `['open', 'close', 'handler']`
(c)* `['open', 'handler', 'close']`
(d) `['open', 'handler']`
=> A `yield` dependency runs its set-up first, then the endpoint, and its `finally` clean-up afterwards.
!py assert same(ans, stem)

?2 [Errors] What does this program print?

```python
from fastapi.testclient import TestClient

app = FastAPI()

    if uid != 1:
        raise HTTPException(status_code=404, detail="no such user")

c = TestClient(app)

```
(a) `404 {'error': 'no such user'}`

(c)* `404 {'detail': 'no such user'}`
(d) `200 {'detail': 'no such user'}`
=> `HTTPException` becomes a response with the given status and a JSON body `{"detail": ...}`.

?2 [SQLAlchemy] What does this program print?
```python
from sqlalchemy import create_engine, select
from sqlalchemy.orm import DeclarativeBase, Mapped, Session, mapped_column

class Base(DeclarativeBase):
    pass

class Note(Base):
    __tablename__ = "notes"
    id: Mapped[int] = mapped_column(primary_key=True)
    text: Mapped[str]

engine = create_engine("sqlite://")
Base.metadata.create_all(engine)
with Session(engine) as s:
    n = Note(text="a")
    s.add(n)
    print(n.id)
    s.flush()
    print(n.id)
```
(a) `1 1`
(b) `None None`
(c)* `None 1`
(d) `0 1`
=> The primary key is assigned by the database when the INSERT is sent: `flush()` sends it (still inside the transaction), `commit()` makes it permanent.
!py assert same(ans, stem)

?1 [Security] Which JWT practice is correct?
(a) Put the user's password in the token so the server need not look it up
(b) Decode with whatever algorithm the token header names
(c)* Keep access tokens short-lived and decode with an explicit list of allowed algorithms
(d) Store the signing key in the repository for convenience
=> A JWT is signed, not encrypted, so it must hold no secrets; pinning the algorithms prevents `alg: none` and algorithm-confusion attacks; short lifetimes limit the damage of theft.

?1 [Security] A user changes `/orders/1042` to `/orders/1043` in the URL and sees someone else's order. This is
(a) SQL injection
(b) CSRF
(c)* broken object-level authorisation (BOLA/IDOR)
(d) a cross-origin policy error
=> The endpoint authenticated the caller but did not check that the order belongs to them. Check ownership on every object access.

?2 [Security] What does this program print?
```python
import jwt

token = jwt.encode({"sub": "42"}, "secret", algorithm="HS256")
try:
    jwt.decode(token, "wrong-key", algorithms=["HS256"])
except jwt.InvalidSignatureError:
    print("rejected")
print(jwt.decode(token, options={"verify_signature": False})["sub"])
```
(a) `rejected None`
(b) `rejected KeyError`
(c)* `rejected 42`
(d) `42`
=> The wrong key fails signature verification, but the payload is only base64-encoded, not encrypted: anyone can read it without the key.
