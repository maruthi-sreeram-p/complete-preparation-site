?1 [Part 1 · Platform] The reference implementation of Python, CPython, runs your source by
(a) compiling it straight to machine code with a JIT
(b)* compiling it to bytecode (cached in .pyc files for imported modules) and interpreting that bytecode on a virtual machine
(c) translating it to Java bytecode for the JVM
(d) interpreting the source text line by line with no intermediate form
=> CPython tokenises, parses to an AST, compiles to a code object holding bytecode and runs it on its evaluation loop. Experimental JITs exist from 3.13, but the model is still bytecode plus interpreter.
