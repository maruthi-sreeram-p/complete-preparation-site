?2 [Instruction set and addressing] An instruction set has 64 opcodes and 3-register instructions that name registers from a set of 32. The minimum number of bits needed to encode such an instruction is
(a) 18
(b)* 21
(c) 24
(d) 32
=> 64 opcodes need 6 bits and each of the 3 register operands needs log₂ 32 = 5 bits: 6 + 15 = 21.
!py assert num(ans) == 6 + 3 * 5

?2 [Instruction set and addressing] An instruction word is 16 bits long and every address field is 4 bits wide. The encoding has 14 three-address instructions and 30 two-address instructions. Using the expanding-opcode technique, the maximum number of one-address instructions that can be encoded is
(a) 16
(b)* 32
(c) 48
(d) 64
=> The first 4 bits give 16 codes. 14 are used, leaving 2, and each expands by 4 bits into 16 two-address opcodes: 32 slots. 30 are used, leaving 2, and each expands by 4 more bits into 16 one-address opcodes: 2 × 16 = 32.
!py assert num(ans) == ((16 - 14) * 16 - 30) * 16

?1 [Instruction set and addressing] In which addressing mode is the effective address equal to the contents of a register?
(a) immediate
(b) direct
(c)* register indirect
(d) PC-relative
=> In register indirect mode the register holds the address of the operand. In immediate mode the operand is in the instruction, in direct mode the address is in the instruction, and PC-relative adds an offset to the PC.

?1 [Instruction set and addressing] The instruction LOAD R1, 100(R2) uses displacement addressing and R2 holds 2000. The effective address of the operand is
(a) 100
(b) 1900
(c) 2000
(d)* 2100
=> The effective address is the register contents plus the displacement: 2000 + 100 = 2100.

?2 [Instruction set and addressing] A 4-byte branch instruction is at address 1000 and uses PC-relative addressing with an offset of +20. The PC has already been incremented to point to the next instruction. The branch target address is
(a) 1020
(b)* 1024
(c) 1004
(d) 1028
=> The PC holds 1000 + 4 = 1004 when the offset is added, so the target is 1004 + 20 = 1024.
!py assert num(ans) == 1000 + 4 + 20

?2 [Instruction set and addressing] A single-word instruction uses memory-indirect addressing for its source operand. Counting the instruction fetch, the number of memory accesses needed to obtain the operand is
(a) 1
(b) 2
(c)* 3
(d) 4
=> One access fetches the instruction, a second reads the pointer stored at the address given in the instruction, and a third reads the operand at the address of that pointer: 3.

?2 [Instruction set and addressing] X = (A + B) × (C + D) is to be computed on an accumulator (one-address) machine with LOAD, STORE, ADD and MUL instructions. The minimum number of instructions needed is
(a) 5
(b) 6
(c)* 7
(d) 8
=> LOAD A, ADD B, STORE T, LOAD C, ADD D, MUL T, STORE X. The temporary T is needed because the accumulator can hold only one partial result.

?2 [Instruction set and addressing] A 32-bit word 0x12345678 is stored at address 100 in a little-endian machine. The byte stored at address 100 is
(a) 0x12
(b) 0x34
(c) 0x56
(d)* 0x78
=> Little-endian stores the least significant byte at the lowest address: 100 → 0x78, 101 → 0x56, 102 → 0x34, 103 → 0x12.

?2 [Instruction set and addressing] Which of the following is a typical feature of a RISC architecture?
(a)* Load–store architecture with fixed-length instructions
(b) A large number of complex addressing modes
(c) A microprogrammed control unit as the standard design
(d) Variable-length instructions with memory operands in ALU instructions
=> RISC machines restrict memory access to load and store instructions, use a few fixed-length formats and usually a hardwired control unit. The other options describe CISC designs.

?2 [Arithmetic and ALU] The number of add or subtract operations that Booth's algorithm performs for the 4-bit multiplier 1101 is
(a) 1
(b) 2
(c)* 3
(d) 4
=> With an appended 0 on the right, the bit pairs (bᵢ, bᵢ₋₁) from the right are (1,0) subtract, (0,1) add, (1,0) subtract and (1,1) no operation. That is 3 operations.
!py assert booth_ops('1101', 4) == num(ans)

?2 [Arithmetic and ALU] Which 8-bit multiplier needs the largest number of add/subtract steps in Booth's algorithm?
(a) 11111111
(b) 00000000
(c)* 01010101
(d) 00001111
=> Booth acts at every boundary between a 0 and a 1 (with 0 appended on the right). The alternating pattern 01010101 has such a boundary at every position, giving 8 operations, while 11111111 needs 1, 00001111 needs 2 and 00000000 needs 0.
!py assert max(['11111111', '00000000', '01010101', '00001111'], key=lambda s: booth_ops(s, 8)) == ans

?2 [Arithmetic and ALU] An 8-bit ALU adds 0xFF and 0x01 (the 8-bit result is 0x00). Which flags are set?
(a)* Zero and carry, but not overflow
(b) Zero and overflow, but not carry
(c) Carry and overflow, but not zero
(d) Only zero
=> The 9-bit sum is 0x100, so the carry out is 1 and the 8-bit result is zero, so Z = 1. As signed numbers this is (−1) + 1 = 0, which does not overflow: both carries around the sign bit are 1, so their XOR is 0.
!py
a, b = 0xFF, 0x01
total = a + b
signed = lambda x: x - 256 if x >> 7 else x
assert total >> 8 == 1 and total & 0xFF == 0 and -128 <= signed(a) + signed(b) <= 127

?2 [Arithmetic and ALU] Dividing an 8-bit unsigned number by another 8-bit unsigned number using restoring division requires how many shift-and-subtract iterations?
(a) 4
(b) 7
(c)* 8
(d) 16
=> The algorithm produces one quotient bit per iteration, so an 8-bit quotient needs 8 iterations.

?2 [Arithmetic and ALU] Two 16-bit unsigned integers are multiplied. The minimum number of bits needed to hold every possible product is
(a) 16
(b) 17
(c) 31
(d)* 32
=> The largest product is (2¹⁶ − 1)² = 2³² − 2¹⁷ + 1, which exceeds 2³¹, so 32 bits are needed (the product of two n-bit numbers needs up to 2n bits).
!py assert (2 ** 16 - 1) ** 2 >= 2 ** 31 and (2 ** 16 - 1) ** 2 < 2 ** 32 and num(ans) == 32

?2 [Arithmetic and ALU] With tree-structured carry-lookahead logic, the addition delay of an n-bit adder grows as
(a) O(n)
(b)* O(log n)
(c) O(1)
(d) O(n²)
=> Lookahead units compute groups of carries in parallel, combining them in a tree whose depth is logarithmic in n. A ripple-carry adder is O(n).

?1 [Control unit] Compared with a microprogrammed control unit, a hardwired control unit is generally
(a)* faster but less flexible
(b) slower and more flexible
(c) faster and more flexible
(d) slower and less flexible
=> Hardwired control is implemented directly in logic, so there is no control-store access and it is faster. Changing it means redesigning the circuit, so it is less flexible.

?2 [Control unit] A microprogrammed control unit has a control memory of 1024 words. Each microinstruction is horizontal with 40 control-signal bits plus a 10-bit next-address field. The size of the control memory in bits is
(a) 40 960
(b)* 51 200
(c) 10 240
(d) 61 440
=> Each word is 40 + 10 = 50 bits, and there are 1024 words: 1024 × 50 = 51 200 bits.
!py assert num(ans.replace(' ', '')) == 1024 * (40 + 10)

?2 [Control unit] In a vertical microinstruction format, three fields choose among 16, 8 and 4 mutually exclusive control signals. Each field must also be able to select "no signal". The minimum number of bits in the control-signal part of the microinstruction is
(a) 9
(b)* 12
(c) 15
(d) 28
=> A field with n signals plus "none" needs ⌈log₂(n + 1)⌉ bits: ⌈log₂ 17⌉ = 5, ⌈log₂ 9⌉ = 4 and ⌈log₂ 5⌉ = 3. The total is 5 + 4 + 3 = 12.
!py assert num(ans) == sum(math.ceil(math.log2(n + 1)) for n in (16, 8, 4))

?2 [Control unit] Compared with vertical microinstructions, horizontal microinstructions are
(a)* wider and allow more parallelism between micro-operations
(b) narrower and allow more parallelism
(c) wider and allow less parallelism
(d) narrower and need more decoding
=> A horizontal format gives each control signal its own bit, so words are long but several signals can be active in the same microinstruction without decoding. A vertical format encodes mutually exclusive signals in fields, so it is narrower but needs decoders and offers less parallelism.

?1 [Control unit] In a microprogrammed control unit, the control address register holds
(a) the address of the next machine instruction
(b)* the address of the next microinstruction
(c) the data to be written to memory
(d) the opcode of the current instruction
=> The control address register (CAR) points into the control store and selects the microinstruction to be executed next. The program counter holds the address of the next machine instruction.

?2 [Cache memory] A direct-mapped cache has a size of 64 KB, a block size of 32 bytes and a 32-bit physical address. The number of tag bits is
(a) 14
(b) 15
(c)* 16
(d) 17
=> Offset = log₂ 32 = 5 bits. Number of blocks = 64 KB / 32 B = 2048, so the index = 11 bits. Tag = 32 − 11 − 5 = 16.
!py assert num(ans) == 32 - int(math.log2(64 * 1024 // 32)) - 5

?2 [Cache memory] A 4-way set-associative cache of size 32 KB has 64-byte blocks and the physical address is 32 bits. The number of tag bits is
(a) 17
(b) 18
(c)* 19
(d) 20
=> Blocks = 32 KB / 64 B = 512. Sets = 512 / 4 = 128, so the index = 7 bits. Offset = 6 bits. Tag = 32 − 7 − 6 = 19.
!py assert num(ans) == 32 - int(math.log2(32 * 1024 // 64 // 4)) - 6

?2 [Cache memory] A fully associative cache of 16 KB has 64-byte lines and a 32-bit address. The tag in each line has
(a) 20 bits
(b) 24 bits
(c)* 26 bits
(d) 32 bits
=> There is no index in a fully associative cache. Only the offset (log₂ 64 = 6 bits) is removed, so the tag is 32 − 6 = 26 bits.

?2 [Cache memory] A direct-mapped cache of 16 KB has 16-byte blocks and a 32-bit address. Each line has a data block, a tag and 1 valid bit. The total number of bits of storage in the cache (data + tags + valid bits) is
(a) 147 456
(b)* 150 528
(c) 131 072
(d) 153 600
=> There are 1024 lines. Offset = 4 bits, index = 10 bits, tag = 32 − 14 = 18 bits. Each line holds 128 + 18 + 1 = 147 bits, so the total is 1024 × 147 = 150 528.
!py assert num(ans.replace(' ', '')) == 1024 * (16 * 8 + 18 + 1)

?2 [Cache memory] A cache has a hit time of 1 ns, a miss rate of 5% and a miss penalty of 20 ns. The average memory access time is
(a) 1.5 ns
(b)* 2 ns
(c) 2.5 ns
(d) 3 ns
=> AMAT = hit time + miss rate × miss penalty = 1 + 0.05 × 20 = 2 ns.

(a) 4 ns

(d) 12 ns

?2 [Cache memory] A processor has a base CPI of 1. 30% of instructions are loads or stores, the data cache miss rate is 2% and the miss penalty is 100 cycles. Instruction fetches always hit. The effective CPI is
(a) 1.3
(b)* 1.6

?2 [Cache memory] A direct-mapped cache has 4 lines. The block addresses 0, 4, 8, 0, 4, 8 are accessed in this order. The number of cache misses is
(a) 3
(b) 4
(c) 5
(d)* 6
=> Blocks 0, 4 and 8 all map to line 0 (address mod 4 = 0), so each access evicts the previous block and every access is a miss: 6 misses.

?2 [Cache memory] A fully associative cache with 3 lines uses LRU replacement. The block references are 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5 and the cache is initially empty. The number of misses is
(a) 8
(b) 9
(c)* 10
(d) 12
=> Tracing LRU gives misses on 1, 2, 3, 4, 1, 2, 5, 3, 4 and 5, and hits on the two references to 1 and 2 after 5. That is 10 misses. (FIFO would give 9.)
!py assert cache_misses([1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5], 1, 3, 'LRU') == num(ans)

?2 [Cache memory] Which cache write policy requires a dirty bit for each cache line?
(a) write-through
(b)* write-back
(c) write-around
(d) none of these
=> Write-back updates memory only when a modified line is evicted, so the cache must remember which lines are dirty. Write-through updates memory on every write and has no need for the bit.

?2 [Cache memory] For a fixed cache capacity, increasing the block size typically
(a)* reduces compulsory misses, but may raise conflict misses and the miss penalty
(b) reduces all three kinds of misses
(c) increases the hit time only
(d) has no effect on the miss rate
=> Larger blocks exploit spatial locality, so fewer first-reference misses occur. But fewer blocks fit in the cache, which can increase conflict misses, and each miss moves more data, so the miss penalty rises.

?2 [Cache memory] A cache miss that happens because the block is referenced for the first time is called a
(a) capacity miss
(b) conflict miss
(c)* compulsory miss
(d) coherence miss
=> First-reference misses are compulsory (cold-start) misses. They occur even in an infinitely large cache.

?2 [Cache memory] An 8-way set-associative cache of 64 KB has 64-byte blocks. The number of sets is
(a) 64
(b)* 128
(c) 256
(d) 1024
=> Blocks = 64 KB / 64 B = 1024. Sets = 1024 / 8 = 128.

?2 [Cache memory] A direct-mapped cache has 64 lines. Memory block number 1234 is placed in cache line number
(a)* 18

?2 [Cache memory] A cache has an access time of 10 ns. On a miss, main memory (100 ns) is accessed after the cache access, so a miss costs 110 ns. The effective access time is 20 ns. The hit ratio is
(a) 0.8

(d) 0.99

(a) 512 bytes

?2 [Cache memory] A cache has 64-byte blocks. The memory has a 50 ns latency for the first transfer and the bus carries 8 bytes every 10 ns. Assuming the miss penalty is the latency plus the bus transfer time of the whole block, the miss penalty is
(a) 60 ns

?2 [Memory system] A 64K × 16 memory is to be built from 16K × 8 memory chips. The number of chips required is
(a) 4
(b) 6
(c)* 8
(d) 16
=> (64K / 16K) rows × (16 bits / 8 bits per chip) columns = 4 × 2 = 8 chips.
!py assert num(ans) == (64 // 16) * (16 // 8)

?2 [Memory system] In the 64K × 16 memory built from 16K × 8 chips, how many of the address lines are used to select between the rows of chips?
(a) 1
(b)* 2
(c) 3
(d) 4
=> The total address space is 64K (16 address lines) and each chip row covers 16K (14 lines). The remaining 16 − 14 = 2 lines feed a 2-to-4 decoder that selects one of the 4 rows.

?1 [Memory system] Which of the following memories needs periodic refreshing of its contents?
(a) SRAM
(b)* DRAM
(c) ROM
(d) Cache memory built from flip-flops
=> A DRAM cell stores charge on a capacitor, which leaks away, so the contents must be refreshed regularly. SRAM keeps its value as long as power is on.

?2 [Memory system] A C program traverses a two-dimensional array row by row (row-major, the layout used by C). This access pattern mainly exhibits
(a)* spatial locality
(b) temporal locality only
(c) no locality
(d) sequential consistency
=> Consecutive elements of a row lie at consecutive addresses, so each fetched cache block serves several following accesses, which is spatial locality.

?1 [Memory system] A byte-addressable memory is addressed with 28 address bits. Its capacity is
(a) 28 MB
(b) 128 MB
(c)* 256 MB
(d) 512 MB
=> 2²⁸ bytes = 2⁸ × 2²⁰ = 256 MB.

?2 [I/O and DMA] A device transfers data at 2 MB/s using DMA with 4-byte words. Each word transfer steals one memory cycle of 100 ns. The fraction of memory time used by the DMA transfers is
(a) 2%
(b)* 5%
(c) 10%
(d) 20%
=> 2 MB/s ÷ 4 bytes = 500 000 transfers per second. At 100 ns each that is 500 000 × 100 ns = 0.05 s per second, or 5%.
!py assert close(2e6 / 4 * 100e-9 * 100, num(ans))

?1 [I/O and DMA] Which I/O techniques let the CPU do useful work while a slow device is preparing data?
(a) programmed I/O only
(b) polling
(c)* interrupt-driven I/O and DMA
(d) none of them
=> In programmed I/O the CPU busy-waits and polls. With interrupts the CPU runs other code until the device signals, and with DMA the controller moves the data itself.

?2 [I/O and DMA] In which DMA transfer mode does the DMA controller retain control of the bus until the entire block has been transferred?
(a) cycle stealing
(b)* burst mode
(c) transparent mode
(d) interleaved mode
=> In burst (block) mode the controller keeps the bus for the whole block, locking out the CPU. Cycle stealing takes the bus for one word at a time, and transparent mode uses only cycles the CPU is not using.

?2 [I/O and DMA] A vectored interrupt scheme is one in which
(a)* the interrupting device supplies a number or address used to find its service routine
(b) the CPU polls every device to find the source of the interrupt
(c) all interrupts jump to one fixed service routine
(d) interrupts are disabled during the service routine
=> In a vectored interrupt the device places a vector on the bus, so the CPU can branch straight to the right routine. Non-vectored schemes need polling or a single shared routine.

?2 [I/O and DMA] In a daisy-chain interrupt priority scheme, the device with the highest priority is
(a)* the one electrically closest to the CPU
(b) the one farthest from the CPU
(c) the one that interrupted first
(d) chosen at random
=> The acknowledge signal passes through the devices in order, starting with the one nearest the CPU, so that device wins whenever it is requesting.

?2 [I/O and DMA] A device raises 1000 interrupts per second. Each interrupt costs the CPU 20 µs of overhead. The fraction of CPU time spent on this overhead is
(a) 0.2%
(b)* 2%
(c) 20%
(d) 0.02%
=> 1000 × 20 µs = 20 ms per second = 2% of the CPU time.
!py assert close(1000 * 20e-6 * 100, num(ans))

?2 [Pipelining] A 5-stage pipeline with a 1-cycle-per-stage design executes 100 instructions with no stalls. The total number of clock cycles needed is
(a) 100

(d) 505

?2 [Pipelining] A 5-stage pipeline with equal stage delays executes 1000 instructions with no stalls. The speedup over a non-pipelined machine (whose instruction time is 5 stage delays) is approximately
(a) 3.75

?2 [Pipelining] A non-pipelined processor needs 10 ns per instruction. A pipelined design splits the work into 5 stages of 2 ns each and adds 0.5 ns of latch overhead per stage. For a very large number of instructions the speedup is

?2 [Pipelining] Consider I1: R1 ← R2 + R3 followed by I2: R4 ← R1 + R5. The dependence between I1 and I2 is a
(a)* RAW hazard
(b) WAR hazard
(c) WAW hazard
(d) structural hazard
=> I2 reads R1 which I1 writes, so it must read after the write: read-after-write (RAW), a true data dependence.

?2 [Pipelining] In a 5-stage pipeline with full forwarding, a load instruction is immediately followed by an instruction that uses the loaded register. The number of stall cycles required is
(a) 0
(b)* 1
(c) 2
(d) 3
=> The loaded value is available only after the MEM stage, but the dependent instruction needs it at the start of its EX stage, one cycle earlier than forwarding can supply it. One bubble is unavoidable.

?2 [Pipelining] A write-after-read (WAR) hazard occurs when
(a)* a later instruction writes a register before an earlier instruction has read it
(b) a later instruction reads a register before an earlier instruction has written it
(c) two instructions both write the same register in the wrong order
(d) two instructions need the same functional unit in the same cycle
=> WAR is an anti-dependence: the later instruction's write must not overtake the earlier instruction's read. (b) is RAW, (c) is WAW and (d) is a structural hazard.

?2 [Pipelining] A pipelined processor has a single memory port used both for instruction fetch and for data access. When a load or store is in its MEM stage, an instruction fetch also wants the memory in the same cycle. This situation is called a
(a) data hazard
(b) control hazard
(c)* structural hazard
(d) write-after-write hazard
=> Two instructions competing for the same hardware resource in the same clock cycle is a structural hazard. It is avoided by separate instruction and data caches or by stalling.
