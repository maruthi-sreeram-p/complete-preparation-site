?1 [Number systems] The largest positive integer that an 8-bit 2's complement number can represent is
(a)* 127
(b) 128
(c) 255
(d) 256
=> The 8-bit range is −128 to +127 (−2⁷ to 2⁷ − 1). 255 would be the largest unsigned value.
!py assert num(ans) == 2 ** 7 - 1

?1 [Number systems] The 8-bit 2's complement representation of −25 is
(a)* 11100111
(b) 11100110
(c) 10011001
(d) 00011001
=> 25 = 00011001. Invert the bits to get 11100110 and add 1 to get 11100111. (11100110 is the 1's complement; 10011001 is the sign-magnitude form.)
!py assert ans == format((-25) & 0xFF, '08b')

?2 [Number systems] The 8-bit pattern 11110000, read as a 2's complement number, has the decimal value
(a) −112
(b)* −16
(c) 16
(d) 240
=> The sign bit is 1, so the value is −128 + 64 + 32 + 16 = −16. (240 is its unsigned value.)
!py assert num(ans) == 0b11110000 - 256

?2 [Number systems] Two 8-bit 2's complement numbers, 01100100 (100) and 01100100 (100), are added. The 8-bit result and the overflow status are
(a)* −56, with overflow
(b) 200, with no overflow
(c) −56, with no overflow
(d) 56, with overflow
=> 100 + 100 = 200 = 11001000, which as an 8-bit 2's complement number is −56. Two positive operands gave a negative result, so signed overflow occurs.
!py assert ans.startswith('−56') and 'with overflow' in ans and (100 + 100) & 0xFF == 200 and 200 - 256 == -56

?2 [Number systems] The smallest number of bits n such that every integer from −500 to +500 can be represented in n-bit 2's complement is
(a) 9
(b)* 10
(c) 11
(d) 12
=> With n bits the range is −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1. 9 bits give −256 to 255, which is too small. 10 bits give −512 to 511, which covers ±500.
!py assert num(ans) == next(n for n in range(1, 64) if 2 ** (n - 1) - 1 >= 500 and -(2 ** (n - 1)) <= -500)

?1 [Number systems] Which of the following representations of signed integers have two different representations of zero?
(a) 2's complement only
(b)* sign-magnitude and 1's complement only
(c) 2's complement and 1's complement only
(d) sign-magnitude, 1's complement and 2's complement
=> Sign-magnitude has +0 = 0000 and −0 = 1000. 1's complement has 0000 and 1111. In 2's complement, inverting 0000 and adding 1 gives 0000 again, so zero is unique.

?2 [Number systems] The binary representation of the decimal fraction 0.625 is
(a)* 0.101
(b) 0.011
(c) 0.110
(d) 0.1001
=> 0.625 = 1/2 + 1/8 = 0.101₂. By repeated doubling: 0.625 × 2 = 1.25 (digit 1), 0.25 × 2 = 0.5 (0), 0.5 × 2 = 1.0 (1).
!py assert ans == '0.101' and Fraction(1, 2) + Fraction(1, 8) == Fraction(5, 8)

?2 [Number systems] The Gray code equivalent of the binary number 1011 is
(a)* 1110
(b) 1101
(c) 1010
(d) 1111
=> The first Gray bit equals the first binary bit, and each later Gray bit is the XOR of consecutive binary bits: 1, 1⊕0 = 1, 0⊕1 = 1, 1⊕1 = 0. That gives 1110.
!py assert ans == format(0b1011 ^ (0b1011 >> 1), '04b')

(d) 1001 0001
=> BCD encodes each decimal digit separately in 4 bits: 9 = 1001 and 3 = 0011.

?1 [Boolean algebra and minimization] The expression A + A′B simplifies to
(a)* A + B
(b) AB
(c) A
(d) A′ + B
=> Distribute: A + A′B = (A + A′)(A + B) = A + B.

?1 [Boolean algebra and minimization] The expression (A + B)(A + C) simplifies to
(a)* A + BC
(b) AB + AC
(c) A(B + C)
(d) A + B + C
=> Expand: AA + AC + AB + BC = A(1 + C + B) + BC = A + BC.

?2 [Boolean algebra and minimization] The expression AB + A′C + BC simplifies to
(a)* AB + A′C
(b) AB + BC
(c) A′C + BC
(d) A + BC
=> The term BC is the consensus of AB and A′C. If B and C are both 1, then either A or A′ is 1, so one of the other two terms is already 1. BC is redundant.
!py assert all(((a and b) or ((not a) and c) or (b and c)) == ((a and b) or ((not a) and c)) for a, b, c in itertools.product([0, 1], repeat=3))

?1 [Boolean algebra and minimization] In the Quine–McCluskey (tabular) method, two product terms can be combined into one larger term if they differ in
(a)* exactly one bit position
(b) exactly two bit positions
(c) any number of bit positions
(d) only the most significant bit
=> Terms that differ in one literal, say xA and xA′, combine to x. The differing bit becomes a dash. Terms that differ in more than one position cannot be merged in a single step.

?2 [Boolean algebra and minimization] f(A, B, C, D) = Σm(0, 1, 2, 5, 6, 7, 8, 9, 10, 14). The number of literals in a minimum sum-of-products expression for f is

?2 [Boolean algebra and minimization] For the same function f(A, B, C, D) = Σm(0, 1, 2, 5, 6, 7, 8, 9, 10, 14), how many essential prime implicants does the K-map have?

(b)* 2
(c) 3
(d) 4

?2 [Boolean algebra and minimization] The number of different self-dual Boolean functions of 3 variables is
(a) 8
(b)* 16
(c) 64
(d) 256
=> A self-dual function satisfies f(x′) = (f(x))′, so the value on one row of each complementary pair fixes the value on the other. The 8 rows form 4 complementary pairs, each with 2 choices, giving 2⁴ = 16. In general there are 2^(2ⁿ⁻¹) self-dual functions.
!py
count = 0
for t in range(256):
    f = [(t >> i) & 1 for i in range(8)]
    if all(f[7 - i] == 1 - f[i] for i in range(8)):
        count += 1
assert count == num(ans)

?2 [Boolean algebra and minimization] The minimum number of 2-input NAND gates needed to implement f = AB + CD (the inputs are available in true form only) is
(a)* 3
(b) 4
(c) 5
(d) 7
=> AB + CD = ((AB)′ · (CD)′)′ = NAND(NAND(A, B), NAND(C, D)). That is 2 first-level gates and 1 output gate.

?2 [Boolean algebra and minimization] The minimum number of 2-input NAND gates required to implement a 2-input XOR gate is
(a) 3
(b)* 4
(c) 5
(d) 6
=> Let N = NAND(A, B). Then XOR = NAND(NAND(A, N), NAND(B, N)). That is 4 gates in total.
!py
nand = lambda x, y: 1 - (x & y)

?2 [Combinational circuits] A 4 : 1 multiplexer with select inputs A (high) and B (low) implements f(A, B, C) = Σm(1, 2, 6, 7). The data inputs I₀, I₁, I₂, I₃ (for AB = 00, 01, 10, 11) should be
(a)* C, C′, 0, 1
(b) C, C′, 1, 0
(c) C′, C, 0, 1
(d) 0, 1, C, C′

!py

sel = {(0, 0): lambda c: c, (0, 1): lambda c: 1 - c, (1, 0): lambda c: 0, (1, 1): lambda c: 1}

?1 [Flip-flops] A JK flip-flop with J = K = 1 (on each active clock edge)
(a) holds its state
(b) is set
(c) is reset
(d)* toggles
=> The characteristic equation Q⁺ = JQ′ + K′Q gives Q⁺ = Q′ when J = K = 1.

?1 [Flip-flops] The characteristic equation of a T flip-flop is
(a) Q⁺ = T
(b)* Q⁺ = T ⊕ Q
(c) Q⁺ = TQ
(d) Q⁺ = T + Q
=> The T flip-flop toggles when T = 1 and holds when T = 0, which is exactly Q⁺ = T ⊕ Q.

?2 [Flip-flops] A D flip-flop is to be used as a T flip-flop. The input D must be connected to
(a)* T ⊕ Q

(c) TQ
(d) T + Q
=> A D flip-flop gives Q⁺ = D. For T behaviour we need Q⁺ = T ⊕ Q, so D = T ⊕ Q.

?2 [Flip-flops] A JK flip-flop is to be used as a D flip-flop with data input D. The correct connections are
(a)* J = D, K = D′

?2 [Flip-flops] The race-around condition in a level-triggered JK flip-flop occurs when
(a)* J = K = 1 and the clock pulse stays high longer than the propagation delay
(b) J = K = 0 and the clock is high
(c) J = 1, K = 0 and the clock is low
(d) J ≠ K at the clock edge
=> With J = K = 1 the output toggles, and the new output feeds back while the clock is still high, so it toggles again and again. Edge triggering or a master–slave flip-flop prevents this.

?2 [Flip-flops] For an SR latch built from two cross-coupled NOR gates, the forbidden input combination is

(c) S = 1, R = 0
(d) S = 0, R = 1
=> With S = R = 1 both NOR outputs are forced to 0, so Q = Q′ = 0, which violates complementary outputs and leaves an unpredictable state when the inputs return to 0. S = R = 0 simply holds the state.

?1 [Flip-flops] For an SR flip-flop with S = 0 and R = 0, and present state Q = 1, the next state is
(a)* 1
(b) 0
(c) undefined
(d) toggles

?2 [FSM and timing] The minimum number of states in a Mealy machine that detects the overlapping sequence 101 on a serial input is

(d) 5
=> States: nothing useful seen, seen "1", seen "10". Seeing a 1 in the last state outputs the detection and returns to the state "seen 1", which allows overlap. So 3 states suffice.

?2 [FSM and timing] The minimum number of states in a Moore machine that detects the overlapping sequence 101 on a serial input is
(a) 2
(b) 3
(c)* 4
(d) 5
=> A Moore machine needs a separate state whose output is 1 (the sequence has just been completed), in addition to the three states of the Mealy design. So 4.

?2 [FSM and timing] A hold-time violation in a synchronous circuit can be fixed by
