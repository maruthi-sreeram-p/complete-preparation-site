(a) 2
(b)* 3
(c) 4
(d) 5
=> The states remember the longest suffix that is a prefix of 01: nothing useful, "0" seen, and "01" seen (accepting). That is 3 states.
!py assert min_dfa_states(lambda w: w.endswith('01'), '01') == num(ans)

?2 [Finite automata] The number of states in the minimal DFA for the language of strings over {a, b} in which the number of a's is divisible by 3 and the number of b's is even is
(a) 5
(b)* 6
(c) 8
(d) 9
=> The state must remember (number of a's mod 3, number of b's mod 2). The two conditions are independent, so the minimal DFA has 3 × 2 = 6 states.
!py assert min_dfa_states(lambda w: w.count('a') % 3 == 0 and w.count('b') % 2 == 0) == num(ans)

(a) 4
(b) 6
(c)* 8
(d) 16
=> A DFA must remember the last three symbols, and every one of the 2³ = 8 combinations leads to a different future behaviour. (An NFA can do it with 4 states by guessing the position.)

(a) 3

(c) 5
(d) 8
=> The states are: nothing matched, "1", "10", and "101 found". The last state is accepting and absorbing, so no dead state is needed.

(c) 4
(d) 5

?2 [Finite automata] A DFA reads a binary number from the most significant bit and accepts if the number is divisible by 5. The minimal DFA has how many states?
(a) 2
(b) 3
(c)* 5
(d) 10
=> The state is the remainder modulo 5 of the number read so far, with δ(r, b) = (2r + b) mod 5. All 5 remainders are distinguishable, and remainder 0 is accepting.
!py assert min_dfa_states(lambda w: int(w or '0', 2) % 5 == 0, '01') == num(ans)

?2 [Finite automata] L₁ is accepted by a complete DFA with m states and L₂ by a complete DFA with n states. Using the product construction, a DFA for L₁ ∩ L₂ needs at most
(a) m + n states
(b)* m × n states

?2 [Finite automata] Which of the following languages over {0, 1} is regular?
(a)* {w : the number of occurrences of the substring 01 in w equals the number of occurrences of 10}
(b) {0ⁿ1ⁿ : n ≥ 0}
(c) {w : the number of 0s in w equals the number of 1s}
(d) {0ᵖ : p is a prime}
=> The occurrences of 01 and 10 alternate along the string, so their counts are equal exactly when w is empty or starts and ends with the same symbol, which a finite automaton can check. (b) and (c) need to count unboundedly, and (d) has growing gaps.
!py
def same_count(w):
    return sum(1 for i in range(len(w) - 1) if w[i:i + 2] == '01') == sum(1 for i in range(len(w) - 1) if w[i:i + 2] == '10')
assert all(same_count(w) == (w == '' or w[0] == w[-1]) for w in strings_upto('01', 10))

?2 [Turing machines and decidability] For a context-free grammar G, which of the following is decidable?
(a) Is G ambiguous?
(b) Is L(G) = Σ*?
(c)* Is L(G) empty?
(d) Is L(G) regular?
=> Emptiness is decidable by marking the non-terminals that can derive a terminal string and checking whether S is marked. Ambiguity, universality and regularity of a CFG are undecidable.

?2 [Turing machines and decidability] The problem "does a given Turing machine accept at least one string?" is
(a) decidable
(b) undecidable and not recursively enumerable
(c)* undecidable but recursively enumerable
(d) regular
=> By Rice's theorem it is undecidable. It is semi-decidable: simulate the machine on all inputs in a dovetailed manner and accept as soon as some simulation accepts.
