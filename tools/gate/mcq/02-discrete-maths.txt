?1 [Propositional logic] Which of the following is logically equivalent to p → q?
(a)* ¬q → ¬p
(b) q → p
(c) ¬p → ¬q
(d) ¬p ∧ q
=> The contrapositive of an implication is always equivalent to it. (b) is the converse: at p false, q true, p → q is true but q → p is false. (c) is the inverse: at p true, q false, p → q is false but ¬p → ¬q is true.
!py
import itertools
imp = lambda a, b: (not a) or b
assert all(imp(p, q) == imp(not q, not p) for p, q in itertools.product([0, 1], repeat=2))
assert any(imp(p, q) != imp(q, p) for p, q in itertools.product([0, 1], repeat=2))

(a) 8

(c) 128
(d)* 256
=> Three variables give 2³ = 8 rows, and each row can map to 0 or 1 independently, so there are 2⁸ = 256 functions.

?1 [Propositional logic] The negation of p → q is
(a)* p ∧ ¬q
(b) ¬p ∧ q
(c) ¬p ∨ q
(d) p → ¬q
=> p → q is ¬p ∨ q, so by De Morgan its negation is p ∧ ¬q. It is the only way for the implication to fail: p true and q false.

?2 [Propositional logic] How many of the following formulas are tautologies?
I. (p → q) ∨ (q → p)
II. (p ∧ q) → (p ∨ q)
III. (p → q) → (q → p)
IV. ¬(p ∧ q) → (¬p ∧ ¬q)
(a) 1
(b)* 2
(c) 3
(d) 4
=> I and II are tautologies. III fails at p false, q true (p → q is true, q → p is false). IV fails at p true, q false (the premise ¬(p ∧ q) is true but ¬p ∧ ¬q is false).
!py
import itertools
imp = lambda a, b: (not a) or b
fs = [lambda p, q: imp(p, q) or imp(q, p), lambda p, q: imp(p and q, p or q),
      lambda p, q: imp(imp(p, q), imp(q, p)), lambda p, q: imp(not (p and q), (not p) and (not q))]
count = sum(all(f(p, q) for p, q in itertools.product([0, 1], repeat=2)) for f in fs)
assert count == num(ans)

?2 [Propositional logic] How many assignments to (a, b, c) satisfy (a ∨ b) ∧ (¬a ∨ c) ∧ (¬b ∨ ¬c)?
(a) 1
(b)* 2
(c) 3
(d) 4
=> If a is false then b must be true (first clause), so c must be false (third clause), giving (0, 1, 0). If a is true then c must be true (second clause), so b must be false (third clause), giving (1, 0, 1). Exactly 2.
!py
import itertools
n = sum(1 for a, b, c in itertools.product([0, 1], repeat=3) if (a or b) and ((not a) or c) and ((not b) or (not c)))
assert n == num(ans)

?1 [Propositional logic] Which of the following sets of connectives is functionally complete?
(a) {∧, ∨}
(b) {→, ∨}
(c) {⊕, ↔}
(d)* {NAND}
=> NAND alone gives NOT (p NAND p) and AND, hence everything. {∧, ∨} and {→, ∨} keep T → T, so they can never produce ¬. {⊕, ↔} can only build affine (linear) functions, so they cannot produce ∧.

?2 [Propositional logic] Given that p ∨ q is true and p ∧ q is false, which of the following must be true?
(a) p ↔ q
(b)* ¬(p ↔ q)
(c) p
(d) q
=> At least one is true and not both, so exactly one is true. Their truth values therefore differ, which is ¬(p ↔ q), i.e. p ⊕ q. Nothing forces p or q individually.

?1 [Propositional logic] The formula ((p → q) ∧ (q → r)) → (p → r) is
(a)* a tautology
(b) satisfiable but not a tautology
(c) a contradiction
(d) true only when p is true
=> This is hypothetical syllogism. To falsify it you need p true and r false, and then p → q forces q true and q → r forces r true, a contradiction. So it is true in every row.

?2 [Propositional logic] Which of the following is equivalent to ¬(p ↔ q)?
(a)* p ⊕ q
(b) ¬p ↔ ¬q
(c) (p → q) ∧ (q → p)
(d) p ∧ q
=> p ↔ q holds when the values agree, so its negation holds exactly when they differ, which is XOR. (b) and (c) are both equivalent to p ↔ q itself.

(d) 4

?1 [First-order logic] The negation of ∀x ∃y P(x, y) is
(a)* ∃x ∀y ¬P(x, y)
(b) ∀x ∃y ¬P(x, y)
(c) ∃x ∃y ¬P(x, y)
(d) ∀x ∀y ¬P(x, y)
=> Push the negation inwards, flipping each quantifier: ¬∀x becomes ∃x ¬, and ¬∃y becomes ∀y ¬. So it becomes ∃x ∀y ¬P(x, y).

?2 [First-order logic] Which formula says "Every student who attends class passes"? (S = student, A = attends class, P = passes)
(a)* ∀x ((S(x) ∧ A(x)) → P(x))
(b) ∀x (S(x) ∧ A(x) ∧ P(x))
(c) ∃x ((S(x) ∧ A(x)) → P(x))
(d) ∀x (S(x) → (A(x) ∧ P(x)))
=> "Every ... who ..." is ∀ with →. (b) claims everything is a student who attends and passes. (c) uses ∃ with →, true as soon as anything is not a student. (d) claims every student attends class.

?2 [First-order logic] Which of the following is NOT a valid equivalence or implication of first-order logic?
(a) ∀x (P(x) ∧ Q(x)) ≡ ∀x P(x) ∧ ∀x Q(x)
(b) ∃x (P(x) ∨ Q(x)) ≡ ∃x P(x) ∨ ∃x Q(x)
(c)* ∀x (P(x) ∨ Q(x)) ≡ ∀x P(x) ∨ ∀x Q(x)
(d) ∃x (P(x) ∧ Q(x)) → (∃x P(x) ∧ ∃x Q(x))
=> ∀ distributes over ∧ and ∃ over ∨, but not ∀ over ∨. Counterexample: domain {1, 2}, P true only at 1, Q true only at 2. Everything satisfies P ∨ Q, yet neither P nor Q holds everywhere.

?2 [First-order logic] Over the domain {1, 2, 3} let P(x, y) mean x + y = 4. Which of these are true? I. ∀x ∃y P(x, y)   II. ∃y ∀x P(x, y)   III. ∃x ∃y P(x, y)
(a) I only
(b)* I and III only
(c) II and III only
(d) I, II and III
=> I is true: y = 4 − x is in {1, 2, 3} for each x. II is false: no single y works for all x (y = 3 only works for x = 1). III is true: x = 1, y = 3.
!py
D = [1, 2, 3]
P = lambda x, y: x + y == 4
I = all(any(P(x, y) for y in D) for x in D)
II = any(all(P(x, y) for x in D) for y in D)
III = any(P(x, y) for x in D for y in D)
assert (I, II, III) == (True, False, True)

?2 [First-order logic] "No student likes homework" is correctly written as

(c) ∃x (S(x) → ¬L(x))
(d) ¬∀x (S(x) → L(x))

?1 [First-order logic] Which of the following inference patterns is NOT valid?
(a) p → q, p; therefore q
(b) p → q, ¬q; therefore ¬p
(c) p ∨ q, ¬p; therefore q
(d)* p → q, q; therefore p
=> (d) is affirming the consequent. With p false and q true both premises hold but the conclusion fails. (a) is modus ponens, (b) modus tollens, (c) disjunctive syllogism, all valid.

?2 [First-order logic] Over the integers with the usual operations, which statement is true?
(a)* ∀x ∃y (x + y = 0)
(b) ∃y ∀x (x + y = 0)
(c) ∀x ∃y (x · y = 1)
(d) ∃x ∀y (x ≤ y)
=> (a) holds with y = −x. (b) needs one y that cancels every x, which is impossible. (c) fails for x = 2 (no integer y with 2y = 1). (d) fails because the integers have no least element.

?2 [Relations and functions] Let f : A → B and g : B → C be functions such that g ∘ f is one-to-one. Which statement must be true?

(b) g is one-to-one
(c) f is onto
(d) g is onto

?2 [Relations and functions] R = {(1,2), (2,3), (3,4)} on {1, 2, 3, 4}. How many ordered pairs are in the transitive closure of R?
(a) 4
(b) 5
(c)* 6
(d) 9
=> The closure adds (1,3), (2,4) and (1,4) to the original three pairs: 6 in total. There are no reflexive pairs because R has no cycles.
!py
R = {(1, 2), (2, 3), (3, 4)}
while True:
    new = {(a, d) for (a, b) in R for (c, d) in R if b == c} - R
    if not new:
        break
    R |= new
assert len(R) == num(ans)

?2 [Posets and lattices] What is the size of the largest antichain in the poset ({1, 2, …, 10}, divisibility)?
(a) 4
(b)* 5
(c) 6
(d) 10
=> The numbers 6, 7, 8, 9, 10 are pairwise non-divisible, so 5 is achievable. No more is possible: the five chains {1,2,4,8}, {3,6}, {5,10}, {7}, {9} cover the set, so by Dilworth the maximum antichain size is at most 5.
!py
import itertools
best = 0
for mask in range(1 << 10):
    s = [i + 1 for i in range(10) if mask >> i & 1]
    if all(a % b and b % a for a, b in itertools.combinations(s, 2)):
        best = max(best, len(s))
assert best == num(ans)
