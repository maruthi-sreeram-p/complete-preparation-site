?1 [Matrix basics] A is a 4 × 3 matrix, B is 3 × 5 and C is 5 × 2. The product ABC has order
(a)* 4 × 2
(b) 3 × 2
(c) 4 × 5
(d) 5 × 3
=> (4 × 3)(3 × 5) = 4 × 5, and (4 × 5)(5 × 2) = 4 × 2.

?1 [Matrix basics] For matrices A and B for which the product is defined, (AB)ᵀ equals
(a) AᵀBᵀ
(b)* BᵀAᵀ
(c) AB
(d) BA
=> The transpose reverses the order of a product: (AB)ᵀ = BᵀAᵀ. The same reversal holds for inverses.

?1 [Matrix basics] If A and B are invertible n × n matrices, (AB)⁻¹ equals
(a) A⁻¹B⁻¹
(b)* B⁻¹A⁻¹
(c) (A + B)⁻¹
(d) A⁻¹ + B⁻¹
=> (AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AA⁻¹ = I. Matrix products are not commutative, so A⁻¹B⁻¹ is generally different.

?2 [Matrix basics] A is a 3 × 3 matrix with det A = 2. The determinant of adj(A) is
(a) 2
(b)* 4
(c) 8
(d) 1/2
=> For an n × n matrix |adj A| = |A|ⁿ⁻¹ = 2² = 4.
!py assert num(ans) == 2 ** (3 - 1)

?2 [Matrix basics] A is a square matrix with A² = A, and A is not the identity matrix. Which statement is TRUE?
(a)* A is singular
(b) A is invertible
(c) det A = 1
(d) A is the zero matrix
=> A(A − I) = 0 with A − I ≠ 0. If A were invertible, multiplying by A⁻¹ would force A = I, contradicting the assumption. So A is singular (det A = 0). A can be a non-zero singular matrix, e.g. diag(1, 0).

?2 [Matrix basics] For A = [[1, 1], [0, 1]], the (1, 2) entry of A¹⁰ is
(a) 1
(b) 2
(c)* 10
(d) 1024
=> Aⁿ = [[1, n], [0, 1]] by induction, because [[1, n], [0, 1]]·[[1, 1], [0, 1]] = [[1, n + 1], [0, 1]]. So the entry is 10.
!py
A = [[1, 1], [0, 1]]
P = [[1, 0], [0, 1]]
for _ in range(10):
    P = matmul(P, A)
assert P[0][1] == num(ans)

?2 [Matrix basics] How many 2 × 2 matrices with every entry from {0, 1} have a non-zero determinant (over the real numbers)?
(a) 4
(b)* 6
(c) 8
(d) 10
=> The determinant ad − bc is non-zero when exactly one of ad, bc is 1 (otherwise it is 0 − 0 or 1 − 1). ad = 1 needs a = d = 1, and bc must be 0 in 3 ways. Symmetrically bc = 1 with ad = 0 in 3 ways. Total 6.
!py assert sum(1 for a, b, c, d in itertools.product([0, 1], repeat=4) if a * d - b * c != 0) == num(ans)

?2 [Matrix basics] For any square matrix A, the matrix A + Aᵀ is always
(a)* symmetric
(b) skew-symmetric
(c) orthogonal
(d) singular
=> (A + Aᵀ)ᵀ = Aᵀ + A = A + Aᵀ, so it is symmetric. It need not be singular (take A = I) or orthogonal.

?2 [Matrix basics] The determinant of a 3 × 3 real skew-symmetric matrix is
(a)* 0
(b) 1
(c) −1
(d) different for different matrices
=> det A = det Aᵀ = det(−A) = (−1)³ det A = −det A, so det A = 0. This holds for every skew-symmetric matrix of odd order.
