?2 [Asymptotics and recurrences] Consider f1(n) = n log n, f2(n) = (log n)^(log n), f3(n) = n² and f4(n) = 2^(√n). The correct order of these functions by asymptotic growth, from slowest to fastest, is
(a) f1, f2, f3, f4
(b)* f1, f3, f2, f4
(c) f3, f1, f2, f4
(d) f1, f3, f4, f2
=> Compare logarithms: log f1 ≈ log n, log f3 = 2 log n, log f2 = log n · log log n (which beats any constant multiple of log n), and log f4 = √n (which beats log n · log log n). So f1 < f3 < f2 < f4.

assert ans == ', '.join(sorted(L, key=L.get))

?2 [Hashing] A table of size 7 uses h(k) = k mod 7 with linear probing. The keys 10, 17, 3 and 24 are inserted in this order. The slot in which 24 is stored is

=> Dijkstra finalises a vertex when it is first removed from the queue, assuming no later path can be shorter. A negative edge can break that assumption. Bellman–Ford and Floyd–Warshall handle negative edges.

?2 [Graph algorithms] The Bellman–Ford algorithm runs on a graph with 7 vertices that has no negative cycle. After how many passes over all edges are the shortest-path distances from the source guaranteed to be final?
(a) 5
(b)* 6
(c) 7
(d) 49
=> A shortest path has at most V − 1 = 6 edges, and pass k fixes all paths of k edges. So 6 passes are enough (a 7th pass is only used to detect negative cycles).

?2 [Graph algorithms] A depth-first search is run on a directed graph. The graph contains a directed cycle if and only if the DFS finds
(a) a tree edge
(b)* a back edge
(c) a forward edge
(d) a cross edge
=> A back edge points from a vertex to one of its ancestors in the DFS tree, closing a cycle. Conversely, every directed cycle forces a back edge.

?2 [Graph algorithms] The directed graph with edges 1→2, 2→3, 3→1, 3→4, 4→5 and 5→4 has how many strongly connected components?
(a) 1
(b)* 2
(c) 3
(d) 5
=> Vertices 1, 2 and 3 form a cycle, so they form one component. Vertices 4 and 5 form a cycle, so they form another. The edge 3→4 goes only one way, so the two components are separate.
