# Computer Organisation Part 3, ISA and the CPU: original questions. Format: see tools/build_gate.py

?2 [Instruction formats] An ISA has 100 different opcodes, and every ALU instruction names three registers out of 64. Using fixed-width fields, the minimum number of bits in such an instruction is
(a) 22
(b) 24
(c)* 25
(d) 27
=> 100 opcodes need ⌈log₂ 100⌉ = 7 bits, and each of the three register fields needs log₂ 64 = 6 bits: 7 + 18 = 25 bits.
!py assert num(ans) == ceil(log2(100)) + 3 * 6

?2 [Expanding opcodes] A 16-bit instruction has 4-bit address fields. The encoding uses 15 three-address instructions, 14 two-address instructions and 30 one-address instructions. With expanding opcodes, the maximum number of zero-address instructions that can still be encoded is
(a) 16
(b)* 32
(c) 48
(d) 64
=> The first 4 bits give 16 codes; 15 are used, leaving 1, which expands into 1 × 16 = 16 two-address codes. 14 are used, leaving 2, which expand into 2 × 16 = 32 one-address codes. 30 are used, leaving 2, which expand into 2 × 16 = 32 zero-address codes.
!py assert num(ans) == ((((16 - 15) * 16) - 14) * 16 - 30) * 16

?1 [Addressing modes] The addressing mode in which the operand is part of the instruction itself is
(a) direct
(b) register indirect
(c)* immediate
(d) indexed
=> In immediate addressing the instruction contains the operand value, so no memory access is needed for it. Direct mode holds the operand's address, and the others compute an address.

?2 [Addressing modes] An indexed load uses register R5 containing 5000 and a displacement of −40. The effective address is
(a) 5040
(b)* 4960
(c) 5000
(d) 4040
=> The effective address of displacement addressing is the register contents plus the displacement: 5000 + (−40) = 4960.
!py assert num(ans) == 5000 - 40

?2 [Addressing modes] A 4-byte branch instruction is at address 2000. It uses PC-relative addressing with an offset of −16 and the PC has already been advanced past the branch. The target address is
(a) 1984
(b)* 1988
(c) 2004
(d) 2020
=> The PC holds 2000 + 4 = 2004 when the offset is added: 2004 − 16 = 1988.
!py assert num(ans) == 2000 + 4 - 16

?2 [Addressing modes] A one-word instruction uses memory indirect addressing for its operand. Counting the instruction fetch, the number of memory references needed to get the operand value is
(a) 2
(b)* 3
(c) 4
(d) 1
=> One reference fetches the instruction, one reads the pointer stored at the address field, and one reads the operand at the address the pointer holds: 3 in total.
!py assert num(ans) == 1 + 2

?2 [Endianness] The 32-bit value 0xA1B2C3D4 is stored at byte address 1000 on a little-endian machine. The byte stored at address 1002 is
(a) 0xA1
(b)* 0xB2
(c) 0xC3
(d) 0xD4
=> A little-endian machine stores the least significant byte at the lowest address: 1000 holds D4, 1001 holds C3, 1002 holds B2 and 1003 holds A1.
!py data = (0xA1B2C3D4).to_bytes(4, "little")
!py assert data[2] == int(ans, 16)

?2 [Datapath] In a single-cycle processor the stage times are: instruction fetch 220 ps, register read 90 ps, ALU 190 ps, data memory 240 ps and register write 80 ps. A load uses all five stages. The minimum clock period for the processor is
(a) 580 ps
(b) 740 ps
(c)* 820 ps
(d) 500 ps
=> The period must accommodate the slowest instruction, the load: 220 + 90 + 190 + 240 + 80 = 820 ps. An R-type instruction (no memory stage) would need only 580 ps, but it still gets a full 820 ps cycle.
!py assert num(ans) == 220 + 90 + 190 + 240 + 80

?1 [Control unit] Compared with microprogrammed control, hardwired control is generally
(a)* faster but harder to modify
(b) slower but easier to modify
(c) faster and easier to modify
(d) slower and harder to modify
=> Hardwired control generates signals directly with logic gates, so there is no control-store lookup and it is faster, but changing it means redesigning the circuit. Microprogrammed control trades speed for flexibility.

?2 [Control unit] A microprogrammed control unit has a control store of 512 microinstructions, each 36 bits wide. The size of the control store in bytes is
(a) 1,152
(b)* 2,304
(c) 4,608
(d) 18,432
=> 512 × 36 = 18,432 bits, and dividing by 8 gives 2,304 bytes. Option (d) is the size in bits.
!py assert num(ans) == 512 * 36 // 8

?1 [Control unit] Compared with a vertical microinstruction format, a horizontal format
(a) uses narrower words
(b) needs more decoding hardware
(c)* has more bits per microinstruction and can specify several control signals at once
(d) can only issue one control signal per cycle
=> A horizontal microinstruction dedicates roughly one bit to each control signal, so it is wide, needs little decoding and allows parallel micro-operations. A vertical format encodes signals into fields: narrower, but it needs decoders and is slower.

?2 [Memory references] On a 1-address (accumulator) machine where every instruction occupies one memory word, the code for x = y + z is LOAD y, ADD z, STORE x. The total number of memory references to execute it is
(a) 3
(b) 4
(c)* 6
(d) 9
=> Each of the 3 instructions is fetched from memory (3 references) and each accesses one data word (3 references): 6 in total.
!py assert num(ans) == 3 + 3

?2 [Instruction counts] The expression X = (A + B) × (C + D) is evaluated on a stack (0-address) machine using PUSH, POP, ADD and MUL. The minimum number of instructions required is
(a) 6
(b) 7
(c)* 8
(d) 9
=> PUSH A, PUSH B, ADD, PUSH C, PUSH D, ADD, MUL, POP X: 8 instructions (4 pushes, 2 adds, 1 multiply, 1 pop).
!py program = "PUSH A,PUSH B,ADD,PUSH C,PUSH D,ADD,MUL,POP X".split(",")
!py assert len(program) == num(ans)

?1 [Procedures] The effect of the RET instruction at the end of a function is to
(a) push the return address onto the stack
(b) jump to the start of the function
(c)* pop the return address from the stack into the program counter
(d) clear the stack pointer
=> CALL pushes the return address and jumps to the callee; RET pops that address into the PC, so execution continues after the call.

?2 [Address bits] A byte-addressable memory of 16 GiB needs how many address bits?
(a) 32
(b) 33
(c)* 34
(d) 36
=> 16 GiB = 16 × 2³⁰ = 2³⁴ bytes, so 34 address bits are needed.
!py assert num(ans) == int(log2(16 * 2 ** 30))

?1 [Registers] The register that holds the address of the memory location to be read or written is the
(a) MDR
(b)* MAR
(c) IR
(d) SP
=> The MAR (memory address register) holds the address; the MDR (memory data register) holds the data transferred. The IR holds the current instruction and the SP the stack top.
