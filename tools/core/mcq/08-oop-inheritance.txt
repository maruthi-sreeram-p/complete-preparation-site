?2 [Overloading] What does this program print?
```java
public class Main {
    static void show(Object o) { System.out.print("Object "); }
    static void show(String s) { System.out.print("String "); }
    public static void main(String[] args) {
        Object o = "hello";
        show(o);
        show("hello");
        show(null);
    }
}
```
(a) Object Object Object
(b) String String String
(c)* Object String String
(d) it does not compile because of the call with null
=> Overloads are chosen from the declared types. `o` is declared Object, so the Object version runs. The literal is a String. For `null`, both overloads apply and the compiler picks the most specific one, String.

?2 [Overriding] What does this program print?
```java
public class Main {
    static class Animal { String sound() { return "..."; } }
    static class Dog extends Animal { @Override String sound() { return "Woof"; } }
    static void speak(Animal a) { System.out.print(a.sound() + " "); }
    public static void main(String[] args) {
        Animal a = new Dog();
        speak(a);
        speak(new Animal());
    }
}
```
(a) ... ...
(b) Woof Woof
(c)* Woof ...
(d) ... Woof
=> `sound` is an overridden instance method, so the version chosen depends on the actual class of the object at run time: Dog's for the first call, Animal's for the second.

?2 [Static methods] What does this program print?
```java
public class Main {
    static class A { static String name() { return "A"; } }
    static class B extends A { static String name() { return "B"; } }
    public static void main(String[] args) {
        A x = new B();
        System.out.println(x.name());
    }
}
```
(a) B
(b)* A
(c) it does not compile
(d) a ClassCastException
=> Static methods are hidden, not overridden, and the call is bound at compile time using the declared type of x, which is A. So A.name() runs.
!py assert printed(stem) == ans.split()

?2 [Fields] What does this program print?
```java
public class Main {
    static class P { String name = "parent"; }
    static class C extends P { String name = "child"; }
    public static void main(String[] args) {
        P p = new C();
        System.out.println(p.name + " " + ((C) p).name);
    }
}
```
(a) child child
(b) parent parent
(c)* parent child
(d) child parent
=> Fields are not polymorphic. The field accessed is the one of the declared type: `p.name` is P's field ("parent") and after the cast `((C) p).name` is C's field ("child").
!py assert printed(stem) == ans.split()

?2 [Construction order] What does this program print?
```java
public class Main {
    static class A { A() { System.out.print("A "); } }
    static class B extends A { B() { System.out.print("B "); } }
    static class C extends B { C() { System.out.print("C "); } }
    public static void main(String[] args) {
        new C();
    }
}
```
(a) C B A
(b)* A B C
(c) C
(d) A C B
=> Each constructor implicitly starts with `super()`, so construction runs from the top of the hierarchy down: A, then B, then C.

?2 [Casting] What does this program print?
```java
public class Main {

        try {

        } catch (ClassCastException e) {

```
(a) text
(b) a compile-time error
(c)* ClassCastException
(d) null
=> The cast compiles because Integer is a subtype of Object, but the object is actually a String, so the run-time check fails with ClassCastException. Guard with `instanceof` before casting.

?2 [Interfaces] What is the result of compiling this code?
```java
public class Main {
    interface A { default String hi() { return "A"; } }
    interface B { default String hi() { return "B"; } }
    static class C implements A, B { }
    public static void main(String[] args) {
        System.out.println(new C().hi());
    }
}
```
(a) prints A
(b) prints B
(c)* a compile-time error: C inherits unrelated defaults for hi() and must override it
(d) a run-time error
=> Two interfaces provide a default method with the same signature, so the compiler cannot choose. The class must override `hi()`, and may call `A.super.hi()` or `B.super.hi()` explicitly.

?2 [Overriding rules] What is the result of compiling this code?

```java
public class Main {

    static class Derived extends Base { void run() { } }
    public static void main(String[] args) { }
}
```
(a) it compiles
(b)* a compile-time error: the overriding method reduces visibility from public to package-private
(c) a compile-time error: run() cannot be overridden
(d) it compiles with a warning

?2 [Polymorphism] What does this program print?
```java
public class Main {
    static class A {
        void f() { g(); }
        void g() { System.out.print("A.g "); }
    }
    static class B extends A {
        @Override void g() { System.out.print("B.g "); }
    }
    public static void main(String[] args) {
        new B().f();
    }
}
```
(a) A.g
(b)* B.g
(c) A.g B.g
(d) nothing
=> `f` is inherited from A, but inside it the call `g()` is `this.g()`, which is dispatched on the actual object (a B), so B's override runs.
!py assert printed(stem) == ["B.g"]

?2 [Pattern matching] What does this program print?

```java
public class Main {

}
```
(a) I1 S2 O
(b) I1 Stwo O
(c)* I1 S3 O
(d) O O O
=> The first element is an Integer (printed as I1), the second a String of length 3 (S3), and the third a Double, which matches neither pattern (O).

?2 [Composition] What does this program print?
```java
import java.util.*;

public class Main {
    static class CountingSet<E> extends HashSet<E> {
        int added = 0;
        @Override public boolean add(E e) { added++; return super.add(e); }
        @Override public boolean addAll(Collection<? extends E> c) { added += c.size(); return super.addAll(c); }
    }
    public static void main(String[] args) {
        CountingSet<String> s = new CountingSet<>();
        s.addAll(List.of("x", "y", "z"));
        System.out.println(s.added);
    }
}
```
(a) 0
(b) 3
(c)* 6
(d) 9
=> HashSet.addAll is implemented by calling add() for each element, so every element is counted once in addAll and once more in the overridden add: 3 + 3 = 6. The subclass relied on an implementation detail of its parent, the fragile base class problem.
!py assert printed(stem) == ans.split()

?1 [Keywords] Which keyword prevents a method from being overridden in subclasses?
(a) static
(b) abstract
(c)* final
(d) sealed
=> A `final` method cannot be overridden. `abstract` requires overriding, `static` methods are hidden rather than overridden, and `sealed` restricts which classes may extend a type.

?1 [Interfaces] Java supports multiple inheritance of
(a) classes only
(b) neither classes nor interfaces
(c)* interfaces, but a class extends only one class
(d) fields only
=> A Java class can extend one class and implement many interfaces. This avoids the state ambiguity of multiple class inheritance.

?1 [Liskov] The Liskov substitution principle says that
(a)* objects of a subclass should be usable wherever objects of the superclass are expected, without breaking the program's correctness
(b) a class should have only one reason to change
(c) classes should depend on abstractions, not on concrete classes
(d) subclasses must override every method of the parent
=> LSP concerns behavioural substitutability of subtypes. Option (b) describes the single responsibility principle and (c) the dependency inversion principle.
