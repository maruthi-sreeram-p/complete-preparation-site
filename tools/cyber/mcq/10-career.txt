# Careers, certifications and interviews: 52 original questions. Format: see tools/build_gate.py (?1 recall, ?2 scenario)

?1 [Careers] Which role is the most natural first step for a Java developer interested in security?
(a) malware reverse engineer
(b)* application security engineer or a security-focused developer role
(c) physical security supervisor
(d) hardware designer
=> AppSec uses existing skills in code, HTTP, databases and frameworks. A developer role with security duties is also a recognised route.

?1 [Careers] A Tier 1 SOC analyst most needs
(a) deep knowledge of kernel exploits
(b)* log reading, networking basics, SIEM familiarity and careful triage
(c) design skills
(d) accounting skills
=> L1 analysts judge alerts quickly and escalate correctly.

?1 [Careers] GRC stands for
(a) Graphics, Rendering, Compression
(b)* Governance, Risk and Compliance
(c) General Router Configuration
(d) Gateway Resource Control
=> GRC analysts work on policies, risk registers, audits and frameworks such as ISO 27001.

?1 [Careers] An MSSP is
(a) a programming language
(b)* a managed security service provider that runs security operations for many client companies
(c) a type of malware
(d) a certification
=> Many entry-level SOC jobs are at MSSPs, because they run 24x7 monitoring for multiple clients.

?1 [Certifications] CompTIA Security+ is best described as
(a) an advanced management certificate for senior leaders
(b)* a vendor-neutral foundation certificate frequently listed in entry-level job posts
(c) a programming exam
(d) a hardware repair licence
=> It covers broad fundamentals. It does not prove hands-on depth by itself.

?1 [Certifications] eJPT is known as
(a) a theory-only test
(b)* a practical entry-level penetration testing exam done in a lab
(c) a cloud billing certificate
(d) a network cabling course
=> Practical exams show that you can do tasks, not only recall terms.

?1 [Certifications] OSCP is generally regarded as
(a) the easiest first certificate
(b)* a demanding hands-on penetration testing exam, usually a later goal
(c) a degree
(d) a Java exam
=> It tests the ability to compromise machines in a timed lab, which is hard for beginners.

?2 [Certifications] A fresher has no projects and plans to sit five certificates in six months. A better plan is
(a) add three more certificates
(b)* build lab and project proof (write-ups, a break-and-fix app, a home SIEM) and sit one or two relevant certificates
(c) stop learning
(d) hide the lack of projects
=> Certificates open doors, but projects show that you can do the work and give you things to discuss in interviews.

?1 [Presenting yourself] On a CV, personal lab work and projects should be listed under
(a) Work Experience, as a security analyst
(b)* Projects and Labs, described accurately
(c) Awards
(d) Languages
=> Learning is valuable but is not job experience, and interviewers will probe it.

?2 [Presenting yourself] A candidate lists "penetration tested production banking systems" for a weekend lab. In an interview this will
(a)* collapse under follow-up questions and damage trust, so describe the real lab and what was learned instead
(b) impress every interviewer
(c) be ignored
(d) count as a certificate
=> Be accurate. Honest descriptions of real projects stand up to questions.

?2 [Presenting yourself] Your GitHub write-up of an active CTF includes the full solution and flag. The platform's rules forbid that. You should
(a) leave it
(b)* remove it and write about the concept instead
(c) add more flags
(d) delete your account
=> Respect platform rules. Concept-level write-ups are allowed and more valuable.

?1 [Interview method] A good first move in a scenario question such as "a server is infected" is to
(a) wipe the disk
(b)* clarify what is known and then contain the damage
(c) ask for a bonus
(d) switch off all logging
=> Clarify first, contain next, then investigate, remediate, prevent and communicate.

?1 [Foundations review] Encrypting a backup protects which CIA property?
(a) availability
(b) integrity
(c)* confidentiality
(d) none
=> Without the key, the contents cannot be read.

?2 [Foundations review] An asset worth 12,00,000 would lose 50% in one incident, which happens once every 3 years. The ALE is
(a) 1,00,000
(b)* 2,00,000
(c) 6,00,000
(d) 4,00,000
=> SLE = 12,00,000 × 0.5 = 6,00,000. ARO = 1/3. ALE = 6,00,000 / 3 = 2,00,000.
!py assert 1200000 * 0.5 / 3 == num(ans.replace(',', ''))

?1 [Foundations review] STRIDE is used for
(a) password storage
(b)* threat modelling
(c) log shipping
(d) key exchange
=> Spoofing, tampering, repudiation, information disclosure, denial of service and elevation of privilege.

?2 [Networking review] A /27 subnet has how many usable host addresses?
(a) 32

(c) 62

?1 [Networking review] Which is the correct TCP connection setup?
(a) ACK, SYN, SYN/ACK
(b)* SYN, SYN/ACK, ACK
(c) SYN, ACK, FIN
(d) RST, SYN, ACK
=> The client starts, the server answers, the client confirms.

?1 [Networking review] Port 443 is used by
(a) FTP
(b) Telnet
(c)* HTTPS
(d) SMTP
=> HTTP over TLS. Port 80 is HTTP, 22 SSH and 25 SMTP.

?2 [Interview classics] "What happens when you type https://example.com in a browser?" Which sequence is the most complete?
(a) HTTP request, then DNS lookup
(b) TLS handshake only
(c)* DNS lookup, TCP connection, TLS handshake with certificate validation, HTTP request and response over the encrypted channel
(d) ARP only
=> Each step has security implications: DNS spoofing, port scans, certificate checks and HTTP-level attacks.

?1 [Interview classics] The difference between hashing and encryption is that
(a) hashing is reversible
(b)* encryption can be reversed with a key, whereas a hash is one-way
(c) they are identical
(d) hashing needs two keys
=> Use hashing for integrity and password storage, encryption for confidentiality.

?1 [Interview classics] A SHA-256 hash in hexadecimal is how many characters long?
(a) 32
(b)* 64
(c) 40
(d) 128
=> 256 bits / 4 = 64 hex characters.
!py assert len(digest('sha256', 'x')) == num(ans)

?1 [Interview classics] Symmetric encryption is typically used for
(a) key exchange only
(b)* encrypting bulk data quickly with a shared key
(c) signing documents
(d) naming servers
=> Asymmetric cryptography exchanges keys or signs, then symmetric cryptography carries the data.

?2 [Interview classics] An interviewer asks how to prevent SQL injection. The strongest answer is
(a) "use a WAF"
(b)* "parameterised queries everywhere, allow-lists for identifiers, a least-privilege database account, generic errors"
(c) "hide the login page"
(d) "escape every quote manually"
=> Fix the cause (data mixed into code) and add layers.

?2 [Interview classics] Which pair of defences best handles XSS and CSRF respectively?
(a) HTTPS and a firewall
(b)* output encoding with a CSP, and SameSite cookies with anti-CSRF tokens
(c) CAPTCHA and logging
(d) hashing and salting
=> XSS is about untrusted data becoming script. CSRF is about unwanted authenticated requests.

?2 [Interview classics] "How do you store passwords?" The best short answer is
(a) encrypt them with AES
(b) hash them with SHA-256
(c)* salted, slow hashing with Argon2id, bcrypt, scrypt or PBKDF2, plus MFA
(d) Base64
=> The hash must be expensive to guess and unique per user.

?2 [Interview classics] When would you prefer server-side sessions to JWTs in a browser app?
(a) never
(b)* when you need easy revocation and the app is a classic web app, using a protected cookie
(c) only for mobile apps
(d) when passwords are short
=> Server sessions are simple to invalidate. JWTs shine for stateless service-to-service use but are hard to revoke before expiry.

?1 [Interview classics] Least privilege means
(a) everyone is an admin
(b)* each identity gets only the access it needs for its task
(c) no one logs in
(d) passwords are short
=> It limits damage when an identity is compromised.

?2 [Interview classics] In a cloud role review you see Action "*" on Resource "*". You would
(a) approve it
(b)* flag it and propose a policy restricted to the exact actions and resources the workload uses
(c) delete the account
(d) add MFA to the policy
=> Full wildcards are the standard anti-pattern. Use Access Analyzer and CloudTrail to find what is really used.

?1 [Interview classics] A zero-day is
(a) a patched vulnerability
(b)* a vulnerability unknown to the vendor, with no patch available
(c) a day without incidents
(d) a type of firewall
=> Defenders use compensating controls until a patch exists.

?2 [Interview classics] A CVSS v3.1 vector AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H has a base score of
(a) 7.5
(b) 8.8
(c)* 9.8
(d) 10.0
=> Network, low complexity, no privileges or user interaction, high impact on all three: 9.8, Critical.

?2 [Interview classics] A 12-character random password drawn from 94 printable characters has about how many bits of entropy?

?2 [Scenario practice] An employee reports that they entered their password on a fake login page from an e-mail. The best first response is
(a) tell them to ignore it
(b)* reset their password, revoke sessions, check sign-in logs and mailbox rules, and search for the same e-mail in other inboxes
(c) delete their account
(d) wait one week
=> Assume the credentials are compromised. Contain, then check what the attacker did and who else received it.

?2 [Scenario practice] A server shows thousands of failed SSH logins followed by one success from the same IP, and a new user was created minutes later. What do you conclude and do?
(a) harmless, scanning is normal
(b)* likely compromise: isolate the host, preserve evidence, disable the new account, investigate persistence, rotate credentials, rebuild
(c) restart SSH only
(d) delete auth.log
=> A successful login after many failures, followed by account creation, fits brute force plus persistence.

?2 [Scenario practice] A developer finds an access key in a commit made three months ago in a private repository. The correct response is
(a) it is private, so nothing
(b)* rotate the key now, review CloudTrail for use, and add secret scanning to prevent a repeat
(c) delete the commit only
(d) rename the repository
=> History retains the key, and many people may have cloned the repository. Rotation is the control.

?2 [Scenario practice] Customers report that a shopping site charged them different prices than shown. Investigation shows the price is sent in a hidden form field. The fix is
(a) hide the field better
(b)* use the price from the server-side catalogue and ignore any price in the request
(c) encrypt the field with JavaScript
(d) rename the field
=> Never trust client-side values for decisions the server owns.

?2 [Scenario practice] A security scan shows the app's TLS configuration allows TLS 1.0 and weak ciphers. The recommended fix is
(a) leave it for compatibility
(b)* disable TLS 1.0/1.1 and weak ciphers, support TLS 1.2 and 1.3, and enable HSTS
(c) switch to HTTP
(d) buy a longer domain name
=> Old protocol versions have known weaknesses. Modern clients support 1.2 and 1.3.

?2 [Scenario practice] A team wants to log request bodies to debug problems. What risk should you raise?
(a) disk usage only
(b)* logs may then contain passwords, tokens and personal data, so mask sensitive fields or avoid logging bodies
(c) none
(d) slower DNS
=> Logs are widely accessible and long lived. Treat them as sensitive.

?2 [Scenario practice] A new endpoint lets users download their invoice as PDF using /invoice/{id}/pdf. What test do you run first?
(a) a port scan
(b)* log in as two users and request user A's invoice with user B's session
(c) a password hash test
(d) a TLS test
=> Object-level authorisation is the likely weakness. This test costs a minute.

?1 [Scenario practice] After an incident, the "lessons learned" meeting should be
(a) used to assign blame
(b)* blameless, producing concrete improvements to controls and processes
(c) skipped
(d) held only with managers
=> Blame leads to concealment. Improvement leads to fewer incidents.

?1 [Scenario practice] Which statement is true about security scanners?

?1 [Interview classics] The main difference between an IDS and an IPS is that an IPS
(a) cannot use signatures
(b)* sits inline and can block the traffic it detects, while an IDS only alerts
(c) works only on e-mail

?2 [Interview classics] A candidate is asked "How would you secure a REST API?" and answers "use HTTPS". The better answer adds
